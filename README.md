# 🛡️ Android Rescue Shield

โปรแกรมกู้ภัยมือถือ Android สำหรับจัดการแอปเจ้าปัญหา:
- แอปแฝงตัวบังคับแสดงโฆษณา (Adware)
- แอปขโมยพื้นที่หน้าจอ / ล็อกหน้าจอ (Screen Hijacker / Overlay Blocker)
- แอปที่รีสตาร์ทเครื่องแล้วเริ่มทำงานทันทีจนกดยกเลิกไม่ทัน
- แอปที่แอบเปิดสิทธิ์ Device Admin จนกดถอนการติดตั้งในมือถือไม่ได้

---

## 🚀 วิธีเปิดใช้งาน (ง่ายที่สุด)

1. ดับเบิ้ลคลิกไฟล์ **`start.bat`**
2. ระบบจะเปิดหน้าต่างโปรแกรม Desktop GUI ขึ้นมาทันทีที่ `http://localhost:3210`

*(หรือรันผ่านคำสั่ง `node server.js` แล้วเปิดเบราว์เซอร์ไปที่ `http://localhost:3210`)*

---

## 📱 วิธีเชื่อมต่อโทรศัพท์มือถือเข้ากับโปรแกรม

1. **เปิด "โหมดนักพัฒนา" (Developer Options) บนมือถือ:**
   * เข้า *การตั้งค่า (Settings)* > *เกี่ยวกับโทรศัพท์ (About phone)*
   * แตะที่ **"หมายเลขบิลด์ (Build Number)"** ติดต่อกัน **7 ครั้ง** จนขึ้นว่า "คุณเป็นนักพัฒนาแล้ว"
2. **เปิด "การดีบัก USB" (USB Debugging):**
   * เข้า *การตั้งค่า* > *ระบบ / ตัวเลือกสำหรับนักพัฒนา (Developer Options)*
   * เลื่อนหาแล้วเปิด **"การดีบัก USB" (USB Debugging)**
3. **เสียบสาย USB เข้าคอมพิวเตอร์:**
   * หากมีป๊อปอัปขึ้นบนหน้าจอมือถือว่า *"อนุญาตการดีบัก USB หรือไม่"*
   * ให้ติ๊กถูกที่ **"อนุญาตเสมอจากคอมพิวเตอร์นี้" (Always allow)** แล้วกด **ตกลง (OK)**

## ⚡ ฟังก์ชันกู้ภัยหลัก

1. **🚨 เมนูกู้ภัยเร่งด่วน (Instant Emergency Kill):**
   * ตรวจจับแบบเรียลไทม์ว่าแอปไหนกำลังแสดงผลอยู่บนสุดของหน้าจอ (Top-most Focus Window)
   * กดปุ่ม **"⚡ สั่งปิดแอปที่บังจอทันที (Force Kill)"** เพื่อยุติการทำงานของแอปตัวนั้นทันที หน้าจอมือถือจะหลุดจากการล็อกและกลับมาใช้งานได้ทันที
2. **🗑️ ถอนการติดตั้งแบบเด็ดขาด (Force Uninstall):**
   * ลบแอปเจ้าปัญหาออกจากเครื่องผ่านคำสั่ง ADB ทันที โดยไม่ต้องไปกดบนหน้าจอมือถือ
   * ปลดสิทธิ์ **Device Admin** อัตโนมัติ (สำหรับแอปไวรัสที่แอบล็อกสิทธิ์ป้องกันการลบ)
3. **🔍 ตรวจวิเคราะห์ความเสี่ยงของแอป (Smart Risk Scanner):**
   * สแกนสิทธิ์อันตรายที่ส่อแววเป็น Adware:
     * `SYSTEM_ALERT_WINDOW`: สิทธิ์วาดทับหน้าจอ (ตัวการสำคัญของโฆษณาบังจอ)
     * `RECEIVE_BOOT_COMPLETED`: สิทธิ์เริ่มทำงานทันทีเมื่อเปิดเครื่อง
     * `BIND_ACCESSIBILITY_SERVICE`: สิทธิ์การเข้าถึง / บังคับคลิก
     * `NO LAUNCHER ICON`: ซ่อนตัว ไม่มีไอคอนในหน้าหลัก ทำให้หาลบยาก
4. **🛡️ รีบูตเข้า Safe Mode (โหมดปลอดภัย):**
   * สั่งรีสตาร์ทมือถือเข้าสู่ Safe Mode จากคอมพิวเตอร์ได้ด้วยคลิกเดียว

---

## 📋 ข้อกำหนดของระบบ
- **Node.js** (ติดตั้งแล้วในเครื่อง)
- **Android Platform-Tools (ADB)** (ตรวจพบอัตโนมัติที่ `C:\Users\User\AppData\Local\Android\Sdk\platform-tools\adb.exe`)
- สายชาร์จ/สาย USB สำหรับต่อเข้ากับคอมพิวเตอร์
